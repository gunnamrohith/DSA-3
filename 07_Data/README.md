# Predefined Dataset

`catalog.js` is the browser-ready dataset used by the dashboard. It contains 25 DSA algorithm definitions and generates four student-style variants per algorithm for a total of 100 unique submissions.

| Category | Algorithms | Submissions |
| --- | ---: | ---: |
| Sorting | 6 | 24 |
| Searching | 6 | 24 |
| Arrays | 6 | 24 |
| Dynamic Programming | 7 | 28 |
| **Total** | **25** | **100** |

Keep future datasets in this folder so project data remains separate from executable source code.
