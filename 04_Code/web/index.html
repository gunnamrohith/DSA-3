Step-by-Step Architecture & Dataflow Workflow

1

Code Ingestion & Lexical Cleaning (SimplePreprocessor)

Raw source files are accepted from candidates. The preprocessor removes all single-line comments (//) and block comments (/* ... */), standardizes indentation and whitespace, and stores a precise line map so that any discovered plagiarism matches can be projected back to the original source line numbers.

Input: "for ( int i = 0 ; i < n ; i ++ ) { // sort array" ───► Cleaned: "for ( int i = 0 ; i < n ; i ++ ) {"
2

Rabin-Karp Rolling Hash & Winnowing Fingerprinting (CO2, CO6)

Computes rolling polynomial hashes over sliding $k$-grams ($k=12$) using base $B=313$ and prime modulo $M=10^9+7$. The Winnowing algorithm then slides a window of size $w=6$ and selects the minimum hash in each window to compress the fingerprint density while guaranteeing detection of any shared snippet of length $\ge k + w - 1$. Exact string verification is performed to eliminate hash collisions (Las Vegas principle).

Formula: H_new = ((H_old - c_out * B^(k-1)) * B + c_in) mod M [O(1) Rolling Update]
3

Knuth-Morris-Pratt (KMP) Linear Search (CO2)

Extracts code patterns and computes the Longest Prefix-Suffix (LPS / $\pi$) table in $O(M)$ time. Scans the second submission in strict $O(N)$ linear time without backtracking on the text pointer to determine how much of Candidate 2 can be constructed directly from substrings of Candidate 1.

LPS[i] = Length of longest proper prefix of P[0..i] that is also a suffix of P[0..i]
4

Z-Algorithm Linear Prefix Box Matching (CO2)

Maintains an active $[L, R]$ interval window to compute the $Z$-box array in $O(N)$ linear time, quantifying shared structural prefixes between the submissions.

Z[i] = Length of longest common prefix between S and suffix starting at index i
5

Suffix Array + Kasai's LCP Array (Longest Common Substrings) (CO2)

Concatenates the submissions: Code_A + '#' + Code_B. Constructs the Suffix Array using prefix doubling in $O(N \log^2 N)$ and Kasai's LCP Array in $O(N)$ time. By inspecting adjacent suffixes originating from different submissions, the engine discovers the exact Longest Common Substrings (LCS) and pinpoints line coordinates.

Kasai Lemma: LCP(rank[i+1]) >= LCP(rank[i]) - 1 [Guarantees strict O(N) LCP construction]
6

Multi-Metric Consensus Scoring & Verdict

The engine blends all individual signals into a calibrated consensus score: Score = 0.35 * RK + 0.25 * SA + 0.20 * KMP + 0.10 * Z + 0.10 * TFIDF. Outputs a verdict: CRITICAL (> 70%), WARNING (35-70%), or SAFE (< 35%).

DSA-3 Algorithm Theory & Complexity Matrix

CO2 • CO6

Rabin-Karp Rolling Hash

Treats a string of characters as numbers in base $B$ modulo prime $M$. When sliding a window of size $k$ across text $T$, the hash of the next $k$-gram is computed in $O(1)$ constant time by subtracting the contribution of the outgoing character and adding the new incoming character.

Time Complexity: $O(N+M)$ average, $O(N \cdot M)$ worst-case.

Space Complexity: $O(1)$ auxiliary space.

CO2

Knuth-Morris-Pratt (KMP)

Avoids the $O(N \cdot M)$ worst-case of naive search by precomputing the Longest Prefix-Suffix (LPS / $\pi$) table. When a character mismatch occurs, the text pointer $i$ never retreats; instead, the pattern pointer $j$ jumps according to the LPS table.

Time Complexity: Strict $O(N+M)$ worst-case.

Space Complexity: $O(M)$ for the LPS table.

CO2

Z-Algorithm (Z-Function)

Computes $Z[i]$, the length of the longest common prefix between string $S$ and the suffix of $S$ starting at index $i$. By tracking the rightmost match interval $[L, R]$, the algorithm reuses prior computations to achieve strict linear time.

Time Complexity: Strict $O(N)$ linear time.

Space Complexity: $O(N)$ for the $Z$-array.

CO2

Suffix Array + Kasai's LCP

The Suffix Array contains sorted suffix starting indices. Kasai's algorithm constructs the Longest Common Prefix (LCP) array in $O(N)$ time by exploiting the property that the LCP of successive suffixes in the original text decreases by at most 1.

Time Complexity: $O(N \log^2 N)$ construction, $O(N)$ LCP.

Space Complexity: $O(N)$ auxiliary space.

IR • Vector Space

TF-IDF & Cosine Similarity

Treats source code submissions as high-dimensional term frequency vectors. Computes sublinear term frequency weights ($1 + \log(\text{tf})$) and measures the cosine of the angle between Candidate 1 and Candidate 2 in the vocabulary space.

Time Complexity: $O(N)$ linear time.

Space Complexity: $O(\text{Vocabulary})$ space.
